# Relief Donation Pick-Up and Delivery System

A beginner-friendly front-end proof of concept for the proposed Relief Donation Pick-Up and Delivery System in Lambunao, Iloilo.

## Files
- `index.html` — website page structure and donation form
- `style.css` — layout, colors, and responsive styling
- `script.js` — form handling, browser storage, search/filter, and sample status workflow

## How to run
1. Download or clone this repository.
2. Keep the three files in the same folder.
3. Double-click `index.html` to open it in a modern browser.
4. Submit a test donation request and use the tracking section to advance its status.

You can also open the folder in Visual Studio Code and use the Live Server extension.

## Important limitations
This is a front-end prototype only. It does not have a real backend, shared online database, secure login, map integration, email notifications, or role-based administrator accounts. Requests are stored in the browser's local storage on the current device/browser. Do not use real sensitive personal data.
