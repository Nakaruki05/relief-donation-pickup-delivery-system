ABOUT THE PROJECT

How the system is intended to work

01

Submit

The donor enters donation details, pickup location, and preferred date.

02

Review

A charity administrator reviews the request and assigns pickup personnel.

03

Collect

Pickup personnel collect the donation and update its status.

04

Deliver

The donation is delivered to the listed destination and marked as delivered.

Academic prototype: This starter project demonstrates the user interface and a basic client-side workflow. It does not yet provide real accounts, email notifications, map pins, server-side access control, or a shared database.
